# 📊 행사 경비 관리 및 1/N 스마트 정산 시스템

사업/행사 예산 대비 실시간 잔액을 추적하고, 지출 건별 참여자를 다중 지정하여 1인당 예상 분담액 및 최적 송금 경로를 카카오톡 정산서로 출력해 주는 모바일/PC 반응형 웹 애플리케이션입니다.

---

## 💡 데이터베이스(DB)는 어떻게 설정하나요?

이 웹앱은 비싼 유료 DB 서버(MySQL, PostgreSQL 등)를 구축할 필요 없이 **구글 스프레드시트(Google Sheets)와 Google Apps Script(GAS)를 무료 서버리스 실시간 DB**로 사용합니다.

```
[웹 앱 프론트엔드 (GitHub/Vercel)] 
           ↕ (JSON API 통신)
[Google Apps Script (GAS Web App)] 
           ↕
[내 구글 스프레드시트 (영구 저장 및 자동 엑셀 백업)]
```

### 🛠️ DB 설정 3분 완성 가이드

1. **구글 스프레드시트 생성**: 브라우저 주소창에 [sheets.new](https://sheets.new)를 입력해 새 시트를 만듭니다. (예: `2026 하계 워크숍 경비부`)
2. **Apps Script 열기**: 시트 상단 메뉴에서 **[확장 프로그램] > [Apps Script]**를 클릭합니다.
3. **코드 붙여넣기**: 프로젝트의 `gas/Code.gs` 파일 내용 전체를 복사하여 `Code.gs` 창에 덮어씌우고 **저장(Ctrl + S)**합니다.
4. **웹 앱으로 배포하기**:
   - 우측 상단 **[배포] > [새 배포]** 클릭
   - 톱니바퀴 아이콘 클릭 후 **[웹 앱]** 선택
   - **다음 사용자로 실행**: `나(본인 계정)`
   - **액세스 권한이 있는 사용자**: `모든 사용자(Anyone)` 👈 **반드시 선택!**
   - **[배포]** 버튼 클릭 후 구글 계정 권한 승인 진행
5. **웹 앱 URL 복사**: 배포 완료 화면에 나오는 `https://script.google.com/macros/s/.../exec` 형태의 URL을 복사합니다.
6. **웹앱에 입력**: 배포된 웹사이트 상단 **[⚙️ GAS 연동]** 버튼을 누르고 복사한 URL을 붙여넣으면 즉시 연동 완료!

## 🚀 깃허브(GitHub)로 누구나 접속 가능한 웹사이트 배포하기

### 방법 1. Vercel 배포 (가장 추천 - 1분 소요, 기관 제한 없음)
1. 코드를 GitHub 저장소(Repository)에 푸시합니다.
2. [Vercel](https://vercel.com)에 로그인 후 **[Add New...] > [Project]** 클릭
3. 해당 GitHub 저장소를 선택하고 **[Deploy]** 클릭
4. 즉시 `https://내프로젝트.vercel.app` 형태의 고유 주소가 생성되며, 학교/기관 제한 없이 누구나 스마트폰과 PC에서 접속 가능합니다.

---

### 방법 2. GitHub Pages 자동 배포 (무료)
이미 프로젝트에 `.github/workflows/deploy.yml` 파일이 포함되어 있어 깃허브 액션으로 자동 배포됩니다.

1. GitHub 저장소의 **[Settings]** 탭으로 이동합니다.
2. 좌측 메뉴 **[Pages]** 클릭
3. **Build and deployment > Source** 항목을 `GitHub Actions`로 변경합니다.
4. 코드가 `main` 브랜치에 푸시되면 자동으로 빌드되어 `https://<깃허브아이디>.github.io/<저장소이름>/` 주소로 배포됩니다.

## 📱 주요 기능
- **예산 대비 잔액 실시간 모니터링**: 총 행사 예산 대비 집행률, 현재 잔액, 초과 지출 경고
- **지출별 1/N 참여자 선택**: 결제자(1명)와 지출 참여 인원을 다중 선택하여 1인당 부담액 자동 계산
- **최소 송금 알고리즘**: 참여자 간 복잡한 송금 관계를 최소 거래 횟수로 압축
- **카카오톡 정산서 1-클릭 복사**: 계좌번호 및 개인별 송금 금액을 메신저용 포맷으로 즉시 복사
- **시트 양방향 동기화**: 수납/지출 입력 시 구글 시트에 실시간 반영
